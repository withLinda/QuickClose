# Agent onboarding

- Read [`Learnings.md`](Learnings.md) before investigating, editing, or running project workflows; apply its relevant tool and verification guidance.
- Read the current source and configuration before relying on prior-session summaries; treat unresolved entries as unverified.
- After any problem, failed tool call, or bug that requires extra effort to solve, promptly append or update a concise entry in `Learnings.md` while working, not only at session end.
- Record the symptom, cause when known, fix or next step, and actual verification evidence; distinguish verified facts, hypotheses, and open checks.
- Follow the update guidance in `Learnings.md`, keep its front matter and table of contents current, and avoid duplicate entries or sensitive information.
- Before handing off, ensure new learnings and remaining verification gaps are documented; build success or schema validation alone does not prove runtime or visual correctness.
